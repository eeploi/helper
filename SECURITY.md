# Security

eeploi-helper runs as root. We take every report seriously.

## Report a problem

- Email security@eeploi.com.
- Do not open a public issue or pull request for a security problem.
- Tell us the version (`eeploi-helper version`), what you found and how to reproduce it.

## What happens next

- We confirm we got your report within 3 working days.
- We keep your report private until a fixed release is out.
- We credit you in the changelog, unless you ask us not to.

## Supported versions

Only the latest release gets fixes. Update with `sudo eeploi-helper self-update <version>`.
